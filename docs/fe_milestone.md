# 제목 없음

## FE:마일스톤 및 역할분담

- 파일명 및 규칙
    
    [FE_CONVENTIONS.md](%EC%A0%9C%EB%AA%A9%20%EC%97%86%EC%9D%8C/FE_CONVENTIONS.md)
    
    도메인별 폴더 + 소문자 스네이크 케이스로 정한다. 
    
    라우트 함수명과 템플릿명을 일치시켜 백엔드 연동 시 찾기 쉽게 하는 것이 목적이다.
    
    ## 규칙
    
    | 대상 | 규칙 | 예시 |
    | --- | --- | --- |
    | 템플릿 | `templates/도메인/동작.html`, 소문자 스네이크 케이스 | `product/list.html` |
    | 동작 이름 | 목록 `list`, 상세 `detail`, 작성·등록 `new`, 관리 `manage` 로 통일 | `review/new.html` |
    | 공통 컴포넌트 | `templates/components/`, 파일명 앞에 `_` | `_product_card.html` |
    | CSS | 공통은 `common.css`, 화면 전용은 `도메인.css` | `static/css/product.css` |
    | 이미지 | `static/img/도메인/`, 시안용 더미는 `sample_` 접두어 | `static/img/product/sample_ipad.jpg` |
    | 라우트 함수 | `도메인_동작` (템플릿 경로와 대응) | `product_list` → `product/list.html` |
    | 브랜치 | `feat/이름-도메인` | `feat/dayoung-product` |
    
    ## 전체 구조
    
    - 파일 디렉토리 구조도
        
        폴더가 담당자별로 갈리므로 브랜치 간 충돌은 `base.html`과 `components/`에서만 생긴다. 
        
        이 두 곳은 `이다영`만 수정하고, 다른 사람은 변경이 필요하면 요청하는 방식으로 정하는 것이 좋다.
        
        ```
        templates/
        ├─ base.html
        ├─ components/
        │  ├─ _header.html          (이다영)
        │  ├─ _product_card.html    (이다영)
        │  ├─ _pagination.html      (이다영)
        │  └─ _form_fields.html     (이다영: 버튼·칩·입력 매크로)
        ├─ product/                 (이다영)
        │  ├─ list.html
        │  ├─ detail.html
        │  └─ new.html
        ├─ review/                  (허제인)
        │  ├─ list.html
        │  ├─ detail.html
        │  └─ new.html
        ├─ auction/                 (허제인)
        │  ├─ detail.html
        │  └─ end.html
        ├─ chat/                    (허제인)
        │  └─ room.html
        ├─ wanted/                  (김채원)
        │  ├─ list.html
        │  ├─ detail.html
        │  └─ new.html
        ├─ my/
        │  ├─ index.html            (김채원)
        │  └─ manage.html           (허제인)
        └─ auth/                    (김채원)
           ├─ login.html
           └─ signup.html
        static/
        ├─ css/  common.css, product.css, review.css ...
        ├─ js/   (필요 시 도메인.js)
        └─ img/  product/, review/, wanted/, common/
        ```
